# Flappy Bird Game

This is a classic Flappy Bird game built using Python, where you control the bird and try to navigate through obstacles. This game was created by me in 9th grade.

### Features:
- **Simple controls**: Press any key to make the bird flap and avoid pipes.
- **Endless gameplay**: The game continues as long as you don’t collide with a pipe or the ground.
- **Score tracking**: Your score is updated each time you successfully pass through pipes.

### How to Play:
1. Run the Python script.
2. The bird will start falling. Press any key (like Spacebar) to make the bird flap and avoid hitting pipes.
3. Try to navigate through the pipes and keep the bird from touching the ground or colliding with pipes.
4. The score increases as you successfully pass through each pipe.
